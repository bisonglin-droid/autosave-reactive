AutoSave — set it and forget it

A personal auto-save rule that lives on-chain. Deposit test ETH into the DepositBox on Unichain Sepolia; a reactive contract on Reactive Lasna sees the event and, when the deposit is at or above the threshold, triggers a callback that records the auto-save on the SavingsBoard. No bot, no server, no polling.

① DepositBox (Unichain Sepolia, 1301) — you deposit → Deposit event
② AutoSaveReactive (Reactive Lasna, 5318007) — subscribes, react() checks threshold
③ SavingsBoard (Unichain Sepolia, 1301) — callback onDeposit() records the save
